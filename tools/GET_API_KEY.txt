🔑 获取 fal.ai API Key 步骤
================================

1. 打开浏览器访问: https://fal.ai

2. 点击右上角 "Sign Up" 或 "Get Started"
   - 用邮箱注册（Gmail/QQ 邮箱都可以）
   - 或直接用 GitHub/Google 账号登录

3. 注册后会送 $1 免费额度（够生成 2-3 次 3D 模型）

4. 进入 Dashboard: https://fal.ai/dashboard/keys

5. 点击 "Create API Key"，复制生成的 key（格式类似: fal_abc123...）

6. 把 Key 告诉我，或者自己运行：

   Windows CMD:
   set FAL_KEY=你的key
   python tools/gen_3d_avatar.py

   Windows PowerShell:
   $env:FAL_KEY="你的key"
   python tools/gen_3d_avatar.py
